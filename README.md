# Customer Retention & Churn Analysis

## Project
Future Interns - Data Science & Analytics Task 2 (2026)

## Business Question
Why are customers leaving, which segments churn most, how long do customers stay active, and what actions can improve retention?

## Dataset
This project uses a simulated SaaS/subscription customer dataset with 1000 customer records. It is safe for public portfolio use because it contains no real personal data.

## Files
- `customer_retention_churn_analysis.xlsx` - full Excel dashboard and analysis workbook
- `customer_retention_dataset_simulated.csv` - source customer-level dataset
- `customer_retention_churn_report.pdf` - executive report
- `dashboard_preview.png` - dashboard preview image

## Tools Used
- Excel-style dashboard
- Cohort analysis
- Segment analysis
- Churn reason analysis
- Customer lifetime value metrics

## Key Findings
- Overall churn rate: 43.9%
- Retention rate: 56.1%
- Average tenure: 4.8 months
- Average customer lifetime value: $232.32
- Top churn reason: Low product usage

## Recommended Actions
1. Create early onboarding and activation nudges for low-usage customers.
2. Prioritize retention campaigns for Basic-plan customers.
3. Shift marketing budget toward referral and partner channels.
4. Trigger customer success follow-ups for customers with repeated support tickets.
5. Improve billing reminders and payment recovery flows.
